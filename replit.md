# UAE BookGuard - Book Evaluation & Whitelist Report Generator

## Overview
UAE BookGuard is a full-stack web application that evaluates children's and family books for content appropriateness, cultural alignment, and age suitability, specifically for the UAE Ministry of Education. It processes various book formats (PDF, Word, TXT, EPUB, RTF) and **scanned book images** (JPG, PNG, WEBP, GIF, BMP) using OpenAI's GPT-4 Vision for comprehensive evaluation reports. These reports include domain-specific content assessments, age recommendations, and parent discussion guides, ensuring content adheres to Islamic, Arab, and UAE cultural ethics. The system features a sophisticated 4-system evaluation framework, AI deep assessment with evidence-based analysis, OCR-powered scanned book processing, and robust book catalog management.

## User Preferences
Preferred communication style: Simple, everyday language.

## System Architecture

### Frontend Architecture
The frontend is built with React and TypeScript using Vite, utilizing Shadcn/ui (New York style) with Radix UI and Tailwind CSS for styling. TanStack Query manages server state, while Wouter handles client-side routing. Key design elements include a library-first interface with interactive book cards, real-time progress tracking, drag-and-drop file upload, and an illustrative value proposition section. The application includes dedicated About Us and How It Works pages, with interactive back buttons featuring glassmorphism styling. The About Us page features a comprehensive dynamic 4-System Evaluation Framework section with two levels: (1) System overview cards with expandable accordions showing detailed sub-guidelines for each criterion from the active scoring configuration, and (2) Detailed Evaluation Breakdown section displaying rating scales (Safe/Moderate/Severe for Systems 1 & 2), age mapping stages (for System 3), reading proficiency levels (for System 4), and assessment methodology for each criterion. **Expandable Sub-Guidelines System**: Each criterion features a collapsible accordion displaying color-coded detailed guidelines - green for safe/simple/easy content, yellow for moderate concerns, and red/purple/blue for severe/high complexity/advanced content. This design provides transparency while preventing UI overload, allowing users to explore evaluation criteria depth on demand. The Fresh Garden Theme incorporates green-to-cyan gradients and enhanced glassmorphism effects.

### Backend Architecture
The backend uses Node.js with Express.js and TypeScript, providing RESTful endpoints. The file processing pipeline uses Multer for uploads, various libraries for text extraction, and OpenAI API for content analysis. Features include asynchronous processing with progress updates, automatic file cleanup, and a smart text extraction strategy that samples longer books from the beginning, middle, and end.

### Data Storage Solutions
The application primarily uses a PostgreSQL database (Neon serverless) for permanent evaluation persistence, with an automatic fallback to in-memory storage. Drizzle ORM is used for type-safe CRUD operations. Evaluation records include UUID primary keys, file metadata, status, progress, structured JSONB results from AI analysis, base64 encoded cover images, and Amazon age validation data. Dedicated cache tables store Apify API responses: `goodreads_cache` and `amazon_cache`, both with 7-day TTL for performance optimization.

### System Design Choices
The core evaluation uses a **4-System Evaluation Framework**:
1.  **UAE/Islamic/Arab Cultural Values**: Red-line system for cultural alignment.
2.  **General Child Safety**: Red-line system for harmful content.
3.  **Theme Complexity**: Developmental readiness assessment.
4.  **Language Complexity**: Reading level assessment.

Automatic rejection occurs if System 1 or 2 rates "Severe". An "AI Deep Assessment" page provides evidence-based analysis, detailing narrative structure, language metrics, cultural assessment, educational insights, and safety analysis with textual quotes and page references. The assessment header displays age group recommendations and dynamic whitelist status (Whitelisted/Parent Guidance/Not Whitelisted). Book catalog management includes metadata editing and deletion. Batch uploads support sequential processing, real-time queue status, and progress visualization. A dedicated reports page (`/reports`) offers advanced multi-layer filtering for generating dynamic PDF reports. An enterprise-grade scoring configuration administration system (`/admin/scoring`) allows management of evaluation criteria, weights, thresholds, age mappings, and verdict rules with version control and audit trails. PDF reports are generated with a branded design. NMC age band filtering is available on the landing page and Report Generation page. Goodreads integration provides community insights, including overall rating stats, categories, and categorized reviews (Most Helpful, Parent & Educator, Critical Perspectives). **Enhanced Goodreads matching** now fetches 5 results (up from 1) and evaluates all candidates to select the best match based on title/author similarity scoring, with a lowered confidence threshold (30% vs 40%) for better coverage. Amazon age validation provides quality assurance for AI age recommendations by comparing them with publisher-recommended target ages from amazon.ae, displaying side-by-side comparisons in the evaluation results and tracking accuracy metrics in the analytics dashboard. The Amazon integration features **5 major search improvements**: (1) **ISBN-First Matching** - extracts ISBN-13/ISBN-10 from book content for most accurate search (95-100% confidence), (2) **Fuzzy Search with String Similarity** - uses Jaccard similarity algorithm with Unicode normalization and three-tier fallback strategy (ISBN → Title+Author → Title only), (3) **Multiple Edition Comparison** - fetches top 5 editions, compares age ranges, and shows consensus across editions, (4) **Format Preferences** - prioritizes physical books (Hardcover/Paperback) over ebooks, (5) **Confidence Scoring System** - High (95-100%, ISBN match), Medium (70-94%, Title+Author), Low (40-69%, Title only) with match quality badges, match method indicators, and author/publisher verification badges displayed in the UI. **Multi-Source Cover Image System** implements a comprehensive fallback waterfall: (1) Extracted file cover from PDF/EPUB, (2) Goodreads cover (confidence >50%), (3) Amazon cover image from product data (thumbnail/image/mainImage fields), (4) Placeholder icon. Amazon integration now extracts coverImageUrl from product details to serve as a reliable fallback when Goodreads coverage is unavailable, significantly improving cover image availability (90%+ coverage vs previous 60%). Text extraction capacity is increased to 100,000 characters, with a research-backed sampling strategy (35% beginning, 30% middle, 35% end) for longer books, incorporating overlapping chunks and contextual separators. The system supports bulk operations (selection, delete, CSV export) and includes an Analytics Dashboard displaying evaluation metrics, verdict breakdowns, language distribution, top genres, age group distribution, and Amazon age validation accuracy (coverage, match rate, discrepancies). API resilience includes retry logic with exponential backoff for external calls.

## External Dependencies

*   **OpenAI API**: Utilizes `GPT-4o` for book content analysis. GPT-4 Vision is available for PDF OCR if needed via the dedicated GPT-4 Vision service.
*   **Replicate API**: Powers **DeepSeek OCR** for high-accuracy text extraction from scanned book images (JPG, PNG, WEBP, GIF, BMP). Uses `lucataco/deepseek-ocr` model optimized for document OCR with "Free OCR" task type and "Gundam" resolution for best speed/accuracy balance.
*   **Neon Database**: Serverless PostgreSQL for persistent storage.
*   **Apify Goodreads Scraper**: Enriches book data with ratings, reviews, and cover images using `epctex/goodreads-scraper`.
*   **Apify Amazon Scrapers**: Validates AI age recommendations using `pintostudio/amazon-search-products-scraper` for search and `logical_scrapers/amazon-product-scraper` for product details extraction from amazon.ae marketplace. Features ISBN-first matching, fuzzy search with Jaccard similarity, multiple edition comparison, format preferences, and confidence scoring (High/Medium/Low).
*   **String Similarity Library**: `string-similarity` for fuzzy matching book titles and authors with Unicode-aware normalization.
*   **File Processing Libraries**: `pdf-parse`, `mammoth`, `epub-parser`, `rtf-parser`, Node.js `fs`.
*   **PDF Generation**: `Puppeteer` and `Chromium` (Nix package) for HTML-to-PDF conversion.
*   **UI Component Libraries**: `Shadcn/ui`, `Radix UI`, `React Hook Form`, `Zod`, `TanStack Query`, `Wouter`, `Drizzle ORM`.
